# Pixora IA — Plan de Lanzamiento y Crecimiento

## Fase 1: Contenido (Semana 1-2)

### Wallpapers
- [ ] Subir 30+ wallpapers de calidad (4K, originales)
- [ ] Cubrir categorías: Gaming, Anime, Nature, Sci-Fi, Minimal, Dark
- [ ] 5+ wallpapers panorámicos
- [ ] 5+ wallpapers con efecto lluvia (lofi girl style)
- [ ] Marcar 5-8 como "featured" para el hero banner

### Videos (HOT)
- [ ] 15+ video wallpapers de 6 segundos
- [ ] Re-encodear todos con keyframes frecuentes (ffmpeg -g 30)
- [ ] Categorías variadas: Horror, Sci-Fi, Anime, Nature, Pixel
- [ ] Verificar que Explore mode funciona en todos

### Stories
- [ ] 3+ stories con 4-8 frames cada una
- [ ] Captions en español, inglés y japonés
- [ ] Temáticas que cuenten algo (día/noche, estaciones, aventura)

### Day Cycle
- [ ] 3+ temas de ciclo diario
- [ ] Calidad consistente entre las 4 imágenes (mañana/tarde/noche/madrugada)

### Tonos
- [ ] 3+ packs de tonos (gaming, anime, clásicos)
- [ ] 8-12 tonos por pack
- [ ] Verificar que se instalan bien como ringtone/notification/alarm

- [ ] Screenshots actualizados (5-8, mostrando hero banners y Explore mode)
- [ ] Video promocional de 30 segundos
- [ ] Descripción optimizada con keywords (ASO)
- [ ] Categoría: Personalization
- [ ] Rating: Everyone

### Testing

- [ ] Verificar créditos se acumulan correctamente

## Fase 3: Promoción (Semana 3-5)

### Orgánica (gratis)
- [ ] TikTok: 3 videos/semana mostrando wallpapers en acción
- [ ] Instagram Reels: mismos videos adaptados
- [ ] Reddit: r/androidthemes, r/wallpapers, r/anime (donde aplique)
- [ ] YouTube Shorts: tutoriales de Explore mode y features únicos

### Formato de videos promocionales
- Grabación de pantalla mostrando el wallpaper aplicándose
- Touch glow effects en acción
- Explore mode con el dedo controlando el video
- Antes/después del home screen
- Música de fondo trending

### ASO (App Store Optimization)
- [ ] Título: "Pixora IA — Wallpapers, Live Wallpapers & Ringtones"
- [ ] Keywords en descripción: wallpaper 4k, live wallpaper, ringtone, anime wallpaper
- [ ] Responder a todas las reseñas (positivas y negativas)

---

## Fase 4: Monetización (Semana 5-8)

### AdMob
- [ ] Verificar dirección en AdMob (carta de verificación)
- [ ] Configurar cuenta de pagos (banco o Payoneer)
- [ ] Umbral mínimo de pago: $100 USD
- [ ] Monitorear eCPM y fill rate por país

### Registro fiscal
- [ ] Registrarse en el SAT (Régimen Simplificado de Confianza o RESICO)
- [ ] RFC activo para facturación
- [ ] Cuenta bancaria dedicada para el negocio
- [ ] Separar: 30% impuestos, 20% reinversión, 50% ganancia

### Control de ingresos
- [ ] Spreadsheet mensual: ingresos AdMob, gastos, neto
- [ ] Métricas clave: DAU, descargas/día, ads vistos/día, eCPM
- [ ] Revisión semanal de métricas

---

## Fase 5: Crecimiento (Mes 2-3)

### Más contenido
- [ ] Subir 10+ wallpapers por semana
- [ ] Contenido temático (Navidad, Halloween, San Valentín)
- [ ] Wallpapers de tendencia (películas nuevas, juegos populares)

### Features según feedback
- [ ] Leer reseñas de Play Store cada semana
- [ ] Fix bugs reportados en 24-48 horas
- [ ] Features más pedidos → implementar

### Comunidad
- [ ] Permitir que usuarios voten wallpapers (ya tienen likes)
- [ ] Top 10 wallpapers más populares destacados
- [ ] Sección "New this week"

## Fase 6: IA y Premium (Mes 3-6)

### Rama pixora-premium
- [ ] Sistema de créditos conectado a Supabase (ya local)
- [ ] Edge Function + Replicate (Flux) para generar wallpapers
- [ ] In-app purchases via Google Play Billing
- [ ] Paquetes de créditos (500, 1500, 5000, 15000, 50000)
- [ ] Suscripción Pixora Pro ($49 MXN/mes)

### Generación IA
- [ ] Prompt → wallpaper generado en 3-5 segundos
- [ ] Estilos: Anime, Cyberpunk, Fantasy, Minimalist, etc.
- [ ] Imagen de referencia (upload desde galería)
- [ ] Wallpapers generados se suben al catálogo público (comunidad)

### Tonos IA
- [ ] Generación de ringtones con IA (MusicGen o similar)
- [ ] 50 créditos por tono generado

## Notas

- **No hacer todo a la vez** — seguir el orden de las fases
- **Contenido > Features** — mejor 50 wallpapers buenos que 10 features nuevos
- **Escuchar usuarios** — las reseñas dictan qué hacer después
- **Reinvertir** — primeras ganancias van a contenido y promoción

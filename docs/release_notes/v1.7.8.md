## What changed (developer changelog)

Bundles previous v1.7.6 + v1.7.7 + this v1.7.8 bugfix into a single ship-ready AAB. (Earlier versions never reached testers.)

### Banner contrast (from v1.7.7)
- `pixora_daily_banner.dart` is theme-aware via `context.hud.isDark`
- iOS White → Apple Blue Filled (concept #01)
- Black & Gold → keeps original gradient

### AURA brainwave/noise display (NEW in v1.7.8)
- Bug: 5 brainwaves (delta/theta/schumann/alpha/gamma) and pink noise had `hz=null` in DB (column is int, freq is fractional)
- UI was rendering "null" literal in card art and category subtitle
- Fix in `aura_track_card.dart`:
  - Detect by id prefix (`brainwave_*`, `noise_*`)
  - Brainwaves → display name in caps + "binaural" label, waves icon
  - Noise → "PINK" + "noise" label, blur_on icon
  - Category labels: "BINAURAL · BRAINWAVE" / "AMBIENT · NOISE"
  - Solfeggio with valid hz keeps original `{hz}/Hz` display

### Engine mutex (from v1.7.6)
- WallpaperEngineCoordinator broker between AutoRotate / DayCycle / Story
- Each engine claim()s on start, release()s on stop

### Ad behavior reverted (from v1.7.6)
- Removed our 25s/60s safety timeout (was perceived as "ad broken/paused")
- AdMob's native lifecycle handles dismissal

## Cambios técnicos

### AdMob disabled — temporal hasta Production

**Razón**: 2026-05-14 AdMob suspendió la cuenta `pub-6734758230109098` por
29 días detectando "publisher self-clicks" durante testing. Suspensión
irrevocable, segunda ofensa = ban permanente + retención 60 días de ingresos.

**Decisión arquitectural**: apagar AdMob completamente del cliente hasta
que Pixora tenga tráfico real masivo (≥1000 DAU genuinos en Production).
Razón: revenue actual con 5 testers Closed = ~$0-3/mes. No vale el riesgo
de banir la cuenta para siempre por ese monto.

**Cambios en `ad_service.dart`:**
- `_debugDisableAds` getter ahora retorna `true` (intencional, documentado
  in-line, no es leftover como en v1.7.2)
- `initialize()` chequea el flag y skipea `MobileAds.instance.initialize()`
  + `loadInterstitialAd()` cuando está activo
- `showInterstitialAd()` ya tenía el bypass — llama `onAdDismissed()`
  inmediatamente y el usuario recibe credits sin ver UI de ad
- Test device IDs se quedan registrados pero dormant (se activan cuando
  el flag pase a false)

### Para reactivar AdMob (cuando lleguemos a Production)

1. `_debugDisableAds` → `false`
2. `_interstitialAdUnitId` cambiar de TEST `ca-app-pub-3940256099942544/1033173712`
   al production real `ca-app-pub-6734758230109098/6687118537`
3. Verificar `_testDeviceIds` tenga registrados todos los devices de Eduardo
4. Build appbundle + subir a Play Console

## Bug fixes detail

1. **Carousel parallax restored** — `WallpaperCarouselRow` now wraps only the `Transform.translate` in `AnimatedBuilder(animation: scrollController, …)` so cards rebuild on scroll without rebuilding the whole ListView.
2. **`_GlobalHeartbeat` lifecycle bug fixed** — switched from widget-vsync `AnimationController` to a standalone `Ticker` that doesn't depend on any widget's lifecycle. No more crash risk when stats bars dispose out of order.
3. **`SingleTickerProviderStateMixin` → `TickerProviderStateMixin`** — `WallpaperStatsBar` has 3 local AnimationControllers (like/particle/bump). Single mixin allowed only 1, causing `FlutterError: multiple tickers were created` and the **red error box** the user saw on cards. Plural mixin allows N tickers.
4. **`content_manager.downloadAndInstall` aborts on sprite fail** — was returning success after sprite download failure, leaving the user with a static wallpaper instead of the expected animated one with no clear feedback.
5. **Favorites grid overflow** — `childAspectRatio` 0.48 → 0.46 to give the Ticket Stub card +9 dp height; eliminates the 3.7 px bottom overflow visible as the yellow/black warning stripe in debug.

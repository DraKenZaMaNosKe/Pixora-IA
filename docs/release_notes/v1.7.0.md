## Tech highlights

- **LunarPhaseWorker** (Kotlin) — runs every 6h with `NetworkType.CONNECTED` constraint, computes phase via Meeus synodic-month formula offline. On install pre-caches all 8 phase variants for the user's sign so future updates work without internet.
- **12 statue sprites** — polychrome warrior gods, downsampled from source 1080x1920 to 540x960 (saves 23 MB on disk).
- **Moon shadow rewrite** — terminator ellipse formula was inverted; rectangle leaked into transparent corners. Now uses `pieslice` + ellipse mask clipped by moon alpha.
- **Master doc reference**: §16 ARCANO + §17 LiveCalendar.

## Technical notes

- Pixora Island is a live-wallpaper scene (path contains `pixora_island` → triggers `PixoraFriendsRenderer`).
- Background asset: 88 KB WebP uploaded to Supabase `wallpaper-images` bucket.
- Sprite frames (244 PNGs across 4 states) bundled in APK under `assets/pixora_island/`. Same pattern as aquarium and jellyfish.
- State rotation: 75s per slot, IDLE → EAT → SLEEP; night hours (22-06) get extra SLEEP bias. WALK state is bundled but excluded from rotation pending animation polish.
- Soft prompt: shown once per install when balance crosses 100 💎 and user is signed out. Opens HUD bottom sheet with Google sign-in CTA, marked shown in Hive so it doesn't nag.

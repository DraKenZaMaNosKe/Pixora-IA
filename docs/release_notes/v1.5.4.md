## What shipped (full)

### Features (user-visible)
- **AURA module** — new wellness audio tab with lotus icon, positioned after LIVE in the bottom navigation
  - **9 Solfeggio frequencies** generated locally with ffmpeg as pure sine waves (15 min each, loudness normalized to -18 LUFS): 174, 285, 396, 417, 528, 639, 741, 852, 963 Hz
  - **15 nature sounds** — 13 downloaded from Freesound under CC0 license + 2 locally generated (white noise, brown noise), all looped and normalized to 10 min
  - **Bilingual descriptions** ES/EN for every track based on device locale
  - **Full-screen player** with play/pause/loop/seek, sleep timer (5-90 min with gradual fade-out), save offline, track description card
  - **Background playback** — audio continues when the app is closed, with foreground notification controls (via `just_audio_background`)
  - Ads alternados + diamond credits on every track open and offline download (same rules as wallpapers/ringtones)

### Fixes
- **Startup crash**: `MainActivity` now extends `AudioServiceActivity` instead of `FlutterActivity` — required by `just_audio_background` (commit `1b26bee`)
- **Player layout overflow** by 7.4 pixels on tracks with long descriptions (e.g. 528 Hz Milagro) — middle section now uses `Expanded + SingleChildScrollView` (commit `2252f66`)
- **NDK version mismatch warning** — bumped `ndkVersion` to `27.0.12077973` to match plugin requirements (commit `355d8c7`)

### Internal / tooling (not user-visible)
- Complete Claude Code setup: structured permissions, custom skills, commands, hooks, agent, memory system
- CLAUDE.md reduced from 727 to 193 lines (pure signal)
- Master doc §14 with full AURA design + §15 Claude Code standards + §11 canonical secrets source
- New `orbixprivate` repo for user-scope config sync across machines
- AURA content pipeline in `tools/aura/` (ffmpeg + Freesound API + Supabase uploader)

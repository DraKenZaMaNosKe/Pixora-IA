## Tech highlights

### Events section (new)
- **Tab "EVNT"** in bottom nav (between CULT and AURA), pink accent (`#E85A8C`), `Icons.celebration_outlined`
- `EventsService` fetches `events_catalog.json` from `wallpaper-images` bucket — 6h in-memory cache, same pattern as the other catalogs
- `PixoraEvent` model with computed lifecycle: `isActive` / `isUpcoming` / `isPast` based on `starts_at` / `ends_at`
- **Polaroid Album UI** (concept #09 from `pixora_events_concepts.html`):
  - Handwritten "— mi álbum —" header (Caveat font via google_fonts)
  - Active event = big polaroid with `EN VIVO` red pin (rotated), -1.5° angle
  - Upcoming/past = smaller polaroids in horizontal scroll, alternating rotations (-2°, +1.5°, -1°...)
  - Each polaroid uses gradient of the event's `theme_color` + giant translucent emoji icon
  - Pull-to-refresh re-fetches catalog
- **Event detail page** with hero gradient, drop cap description, stats row, tags, placeholder grid for wallpapers, sticky CTA at bottom
- **Pro gating**: locked events show 🔒 placeholder + "Hazte Pro" CTA. Past events accessible only to Pro users.

### Subscription pitch (new)
- `SubscriptionPitchPage` shown right after onboarding completes (concept #02 "Apple Premium")
- Hero: gold-gradient text "Eleva tu experiencia" with radial halo
- 5 features: Cero anuncios, Códices culturales, Eventos exclusivos, AURA ilimitado, Acceso anticipado
- Price card: `$49 MXN/mes`, "Cancela cuando quieras"
- CTA: triggers `SubscriptionService.buyMonthly()` → real Google Play sheet in release builds
- **`kDebugMode` bypass**: in debug APKs (sideloaded), shows snackbar "🧪 Modo desarrollo: compra simulada" instead of opening Play Billing (which always fails for unsigned APKs)
- Skip "Ahora no" → continues to HomePage; Hive flag remembers shown state

### Splash funnel
- Old: splash → either onboarding (then home) or home
- New: splash → onboarding (if not seen) → subscription pitch (if not seen + not Pro) → home
- Each step decides its own next via `onFinish(BuildContext)` callback that uses the active page's context (NOT the splash's context, which is disposed by the time the user finishes)
- Fixes a critical bug where the "¡Comenzar!" button silently did nothing because the captured splash context was unmounted

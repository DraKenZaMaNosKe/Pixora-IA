## Tech highlights

### Cultura section (new)
- New tab "CULT" in bottom nav (between 3D and AURA), gold accent, Material `menu_book_outlined` icon
- Provider `culturaWallpapersProvider` filters by `wallpaper.cultural != null && !isEmpty` from BOTH dynamic_catalog (Postgres) AND catalog_index (JSON canvas_scenes)
- Excludes `iah_egyptian_giza` (already has its own ARCANO section)
- **Zero-recompile content additions**: any new wallpaper that gets a `cultural` block in the catalog appears automatically

### Mictlantecuhtli — first canvas_scene with native particles
- Background: panoramic 2700×1080 cave of the Mictlán
- Sprite: 61-frame god animation (PNG sequence with alpha extracted from original GIF), looping infinitely (no MP4)
- WispSystem: 12 floating soul particles with white-blue halo + parpadeo (sin/cos modulation)
- flash_overlay event: subtle blue pulse every 11 seconds ("breathing" of the underworld)
- Scene spec lives at `wallpaper-scenes/mictlantecuhtli.json` — fully server-side configurable

### Engine improvements
- `SpriteDownloadService.ensureSpritesForScene(spec)` — extracts manifest_keys from any scene spec and downloads sprite ZIPs automatically. New canvas_scene wallpapers no longer need to bump the hardcoded `_themeSprites` map
- `SceneSpecService._fetchAndCache` now invokes `ensureSpritesForScene` after `_fetchImageLayers` — chained dependency resolution
- `WispSystem` and `FireflySystem` use cached `RadialGradient` with `setLocalMatrix` for translation/scaling — eliminates N gradient allocations per frame
- BatteryIndicator receiver paused via `unregisterBatteryReceiver()` in `onVisibilityChanged(false)` mirroring the existing gyro pause

### Code quality
- `CulturalContent` model + `CodexDetailLayout` widget moved from `lib/features/hot_wallpapers/` to `lib/core/` for reusability
- `Wallpaper` and `LiveWallpaper` models both expose `cultural` field with parser
- `kDebugMode` getter replaces hardcoded `_debugDisableAds = false` in AdService — debug builds bypass ads automatically, release builds keep ads on (lesson from v1.7.2)
- Updated `.gitignore`: `.deploy_payload.json`, generated platform files, build artifacts, Claude lock files

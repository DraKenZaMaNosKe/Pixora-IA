## What changed (full developer changelog)

### Privacy & Legal
- **TermsAcceptanceGate** as first-launch gate (Apple Premium concept #01)
- **LegalService** singleton with versioned acceptance (Hive + Supabase audit log)
- Drafted **Terms & Privacy** in es-MX (LFPDPPP-compliant) at `docs/legal/`
  — pending lawyer review
- **Pixora Pro** tile in Perfil deep-links to Play Store cancellation page

### Engagement Analytics
- **AnalyticsService** with batched flush every 30 s (RAM queue, max 500)
- Instrumented in **7 critical points**:
  - bottom-nav tab views
  - event opens
  - AURA listening ticks (30 s heartbeat)
  - subscription pitch funnel (shown / cta_tap / paid)
  - tutorial (started / step / finished)
  - welcome gift (shown / redeemed)
  - terms gate (shown / accepted / declined)
- **Engagement** tab in admin dashboard (4 KPIs + 5 metric tables)
- 8 new `/api/engagement/*` endpoints in `wp_admin_server.py`
- New **migrations applied**:
  - `20260505_007_app_events.sql`
  - `20260505_008_user_terms_acceptance.sql`
- New **`tools/apply_migration.py`** — psycopg2 client (requires IPv4 add-on)

### Reliability fixes
- **AuthService** is `ChangeNotifier`; `signOut` now `disconnect()`s Google
- Concurrent **signIn guard** prevents two-popup race
- **PaymentHistory** reads `user_subscriptions` real schema (was reading wrong columns)
- **AIHistory** reads `ia_generation_queue` (was reading non-existent table)
- Both history pages **re-fetch on auth changes** (no stale data on switch)
- **AdService 60 s safety timeout** against malformed creatives — prevents ANR
  ("Wallpaper Pixora no responde" reproduced and fixed)
- **GracePassService.init()** at app startup
- **WelcomeGiftSheet** wrapped in `SingleChildScrollView` (overflow on short phones)
- **Event detail sticky CTA** respects `MediaQuery.viewPadding.bottom`
  (Samsung 3-button nav was overlapping the button)

### Infrastructure
- IPv4 add-on enabled on Supabase project (~$4/mes) for direct Postgres access
- `KEYS_LOCAL.md` got a **Postgres Direct Connection** section
- `orbixprivate` synced (push hecho)
- `CLAUDE.md` pointer added (no values)
- `tools/wallpapers/dashboard/migrate_now.sql` combined SQL bundle for emergency paste

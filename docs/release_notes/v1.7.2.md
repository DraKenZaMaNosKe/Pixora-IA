## Tech highlights

- **AdService `_debugDisableAds = true`** was a constant left over from local dev. Every interstitial attempt fell through the debug-bypass branch and logged `shown=false`, so the dashboard showed 62 ad attempts in 7 days at **0% fill rate** = $0 ad revenue.
- **Subscription gate** added FIRST (before alternating skip and before debug bypass) so paying users (`SubscriptionService.hasAccess`) never see ads. Logged as `subscriber_skip` for dashboard parity.
- **`_appVersion`** was hardcoded `'1.6.3'` (same bug as in WallpaperStatsService, fixed in v1.7.1). Now uses `PackageInfo.fromPlatform()` lazy-cached.
- **Admin dashboard rebrand** included in this push (server-only, no APK impact): Stripe-style aesthetic, professional copy, name+email displayed everywhere, click-row drill-down, pagination on Top Users by Revenue.

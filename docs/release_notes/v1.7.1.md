## Tech highlights

- **Tracking gaps**: 6 content types had no `trackInstall` call — ARCANO, Stories, Day Cycle, Ringtones, AI Generate, plus AURA missing `trackView`. Each fix fires only after the underlying service confirms success.
- **`app_version`**: was hardcoded `'1.6.3'` in `wallpaper_stats_service._logEvent`. Replaced with `PackageInfo.fromPlatform()` lazy-cached.
- **Admin dashboard** (server-only, no APK impact):
  - `admin_user_stats` view rewritten — auth users collapse across all devices into one row; LEFT JOIN profiles + auth.users for `display_name` + `email`.
  - New RPC `admin_user_detail` for drill-down (devices + per-wallpaper breakdown).
  - Dashboard UI: name+email primary, badge auth/anon, click-row modal, page-size selector + prev/next pagination.
- **Repo hygiene**: 11 root-level tmp/upload scripts that the previous cleanup commit only added to `scripts/archive/` are now properly removed from root.

## Technical notes

- New `AquariumRenderer` + `BubbleRenderer` native Kotlin renderers.
- Extensible `hasAnimatedCanvasOverlay` hook in `PixoraWallpaperService` keeps the engine at 30 FPS for sprite-based wallpapers (fixes clock second-hand lag seen when no audio/rain was active).
- `AquariumRenderer.loadFishSprites` now supports `mirrorOnLoad` for sprite sets whose source faces right (angel, neon).
- `AquariumRenderer.addFish` now accepts `scaleMin/scaleMax/speedMin/speedMax` for per-species variety.
- Sprite sets: betta (61f, 240×442), angel (61f, 240×424, mirrored), neon (60f, 106×48 cropped, mirrored).
- Bubble effect: pure-code, ~1 KB RAM.
- `extract_aquarium_gif.py` helper: auto-skips empty disposal frames, optional content-bbox crop.
- `package_info_plus` added for dynamic version display in Settings.

## Why this release

`parallaxWallpapersProvider` only filtered `dynamic_catalog.json` by tag `'3d'/'parallax'`. The 7 canvas_scene wallpapers live in `catalog_index.json` and don't carry those tags, so the 3D tab rendered empty.

Provider now reads BOTH catalogs and unions them, de-duped by id with the dynamic_catalog version winning when both exist (richer Wallpaper fields). Adapter Wallpaper←CatalogIndexEntry derives image/preview filenames from the `pixora_<id>(_preview).webp` convention. The existing IMAGE→canvas_scene auto-upgrade in `WallpaperService._resolveCanvasSceneFromPath` handles install — no special install path needed for the adapted entries.

Net effect: drop a new entry in `catalog_index.json` with `type: "canvas_scene"` and it appears in the 3D tab automatically — no recompile, no tag bookkeeping required.

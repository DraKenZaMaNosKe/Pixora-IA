## What changed (deeper)

### 🎨 Soft Pastel Pill bottom nav (`b50ae2e`)
Each tab now has its own brand color: Wall=cobalt, Live=red, 3D=violet, AURA=cyan, Stor=amber, Day=gold, Ton=pink, IA=mint, Fav=red-heart, Set=slate. Inactive tabs stay monochromatic. Active tab paints a soft 14% alpha pill with full color icon+label. Same shape on Black & Gold and iOS White.

### 💰 AdService bypass fixes (`1fdbb18`)
Ringtones list, ringtones pack detail, and AI generate were calling install paths directly, skipping `AdService.instance.showInterstitialAd`. That meant skipped impressions + skipped subscription gate. Same wrapper pattern used everywhere else now.

### 🎭 Theme cleanup (`ee47863`)
Cream Day theme was redundant with iOS White. Retired. ThemeService migrates legacy 'day' choice to 'night' silently. -50 lines, -1 theme option, -3 token constants.

### 🔧 Settings polish (`244656e`)
Touch effect picker was 7 stacked rows eating Settings page. Now a single tile that opens a bottom sheet with the full list — same options, much cleaner.

### 🧹 Code health (`6768321`, `3457082`)
- 27 print() → debugPrint() in subscription_service
- 4 unnecessary type checks dropped in auth_service
- 115 withOpacity → withValues(alpha:) across 24 files

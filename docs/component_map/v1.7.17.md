## Para qué sirve este archivo

Inventario de los componentes UI de Pixora con sus textos visibles. Es el **input** para el feature future "Pixora Admin Text CMS" — el dashboard local leerá este mapa para mostrarte qué textos puedes editar sin recompilar la app.

**Convención de versionado:** cada release regenera este archivo (`v1.7.17.md`, `v1.7.18.md`, etc.) vía script en el flow de `pixora-release-prep`. El admin web siempre lee el más reciente.

Premium Stationery

Una carta caligráfica con sello de cera real. El CTA NO es un botón — es una estampa de cera presionada en la carta. Pinyon Script + Cormorant Garamond + Cinzel. Boda real, invitación oficial.

iOS
B&G
Veredicto: ULTRA premium — el usuario siente que RECIBIÓ una invitación, no que se está registrando Sello de cera como CTA es UN MOMENTO — pulso suave, irresistible Rueda perpetua = date picker analógico tipo iPod classic, nostalgia mecánica Pinyon Script requiere cuidar legibilidad — solo título, nunca campos

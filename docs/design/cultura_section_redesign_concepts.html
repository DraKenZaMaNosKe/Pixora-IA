01 · CONCEPT

Codex Manuscript

Cada capítulo es una página de manuscrito iluminado. Drop-cap ornamental, números romanos, marginalia italica, divisores florales y borde deckled. Tipografía Cormorant + Cinzel.

iOS · Cream Vellum
#F3E6C4
#3A2818
#8B1A1A
#0A84FF
B&G · Dark Vellum
#14100A
#0A0805
#D4AF37
#F5D676
Verdict
Pro: ultra distintivo, se siente como un texto sagrado, perfecto para mitología. La drop-cap roja sobre vellum negro es puro fuego ritual.

Contra: requiere disciplina tipográfica férrea; un mal kerning rompe todo el ilusión de manuscrito.

02 · CONCEPT

Museum Exhibit

Cada wallpaper es una pieza catalogada con número de exhibit, placard de bronce, marcas de medición y etiquetas de clasificación. Tipografía Cinzel display + JetBrains Mono para serialización.

iOS · Apple Museum
#FFFFFF
#ECECEC
#1C1C1E
#0A84FF
B&G · Brass Cabinet
#070710
#14141F
#D4AF37
#F5D676
Verdict
Pro: hace que el contenido se sienta curado y educativo, no scrolleado. El usuario percibe la app como una colección, no una galería de stock.

Contra: aesthetics más sterile/academic — puede sentirse frío si los placards son demasiado "British Museum" y poco místico.

03 · CONCEPT

Arcana Deck

Cada capítulo es una carta vertical 3:5 con filigrana ornamental, número en romano, glifos en las esquinas. La lista es una baraja desplegada. El detalle es una carta grande con frase oracular.

iOS · Light Arcana
#FFFFFF
#F8F8FB
#0A84FF
#1C1C1E
B&G · Cosmic Arcana
#0A0A14
#1A1A26
#D4AF37
#F5D676
Verdict
Pro: ultra on-brand con el sistema zodiacal de Pixora (Saint Seiya / cartas cósmicas). Wallpapers se sienten coleccionables. Filigree pulse en B&G es magnético.

Contra: UX menos típica que una lista vertical — puede requerir onboarding o un hint inicial de "desliza para revelar".

04 · CONCEPT

Cinematic Documentary

UX tipo Netflix / Apple TV+ Docs. Featured episode bleed arriba, lista vertical de "capítulos" con thumbnails 16:9, duración tipo "12 min read" y filas por afinidad ("Porque te gustó Egipto").

iOS · Apple TV+
#FFFFFF
#F2F2F7
#1C1C1E
#0A84FF
B&G · Netflix Premium
#000000
#14141F
#D4AF37
#F5D676
Verdict
Pro: UX súper familiar para cualquier usuario que usa streaming. Hace que el contenido se perciba como premium "documental editorial". Conversión a apply alta.

Contra: menos único a Pixora — el usuario podría sentir que es "una galería más". Pierde el feeling sagrado/ritual.

05 · CONCEPT

Ancient Scroll

La sección entera se lee como un pergamino desenrollado. Cap superior, sello de cera al inicio, capítulos con thumbnail circular tipo medallón, divisores ornamentales, cap inferior. Sutil sway animation en la textura.

iOS · Cream Parchment
#F3E6C4
#C9A96A
#3A2818
#8B1A1A
B&G · Aged Vellum
#16100A
#2A1F12
#D4AF37
#F5D676
Verdict
Pro: ULTRA inmersivo, se siente como leer un documento sagrado. La sway animation suave en la textura le da vida. Sello de cera rojo es un detalle ganador.

Contra: scroll fatigue si la lista es larga (50+ capítulos). Mejor con paginación por culturas.

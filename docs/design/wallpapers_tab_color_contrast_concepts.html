// NO. 01
Strict Black & Gold
Eliminar todo verde/azul. Sólo dark + gold. 100% on-brand zodiacal.
★ Coherencia total con la app. Mismo lenguaje que dashboard + LIVE hero. Premium y limpio. Riesgo: menos color para señalizar (categorías no se distinguen por hue).

// NO. 02
Smart Contrasting
Cada pill auto-elige color contrastante (forest verde → pill naranja). Pixora Daily pasa a navy dim.
⚠ Algoritmo bonito pero pesado. Requiere `palette_generator` + lógica per-card. Pills se sienten "random" (¿por qué naranja en Nature?). Útil sólo si la cohesión con el bg importa más que la consistencia.

Mismo tratamiento que el LIVE hero — dark glass + gold hairline en TODOS los overlays.

// NO. 04
Editorial Minimal
Sin pills con fondo. Mono caps + underline gold. Tipografía pura, magazine layout.
✓ Cero clash de color (no hay fills). Restraint elegante. Riesgo: menos atención para CTAs / banner promocional, no enganchan tanto al usuario.

// NO. 05
Cosmic Saint Seiya
Pills con símbolos zodiacales. Pixora Daily con constelaciones animadas. Full Caballeros del Zodiaco.
★ Identidad ULTRA distintiva. Nadie en la categoría wallpaper hace esto. Marketable, coleccionable. Riesgo: aesthetic muy específico, no neutral — define un nicho.

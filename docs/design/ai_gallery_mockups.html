Ten paradigms for browsing the images a user has generated with the in-app AI. Each design commits to a single idea, not a compromise. All share the locked palette (#C9A650 gold on #000 ink) and respect the HUD typography — Fraunces italic for narrative moments, JetBrains Mono for the technical register. None use purple, cyan, pastels, or Inter. All layouts are static + CSS, so CPU cost on-device is negligible.

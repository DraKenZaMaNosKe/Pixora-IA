N° 01

SNKRS Drop

"12,847 in line. Drops in 02:14:08."

Cada evento es una caída tipo Nike SNKRS: hero gigante del wallpaper, raffle live pulsando, tier badge (EXCLUSIVE / RAFFLE / IN-LINE), waitlist counter y countdown chip junto al CTA. El estado "GOT 'EM" se queda como trofeo en pasados. Es el UX más conocido por la generación drop-savvy.

iOS
B&G
PROS
UX ultra familiar para sneakerheads. Urgencia mecánica (raffle + countdown + waitlist). El "GOT 'EM" crea coleccionismo.
CONS
Requiere framing de "raffle" que no embona con todos los eventos. Mucha tipografía bold — reduce respiro visual.
Mi ganadora si el target es Gen Z / sneakerhead. El countdown solo le saca conversión brutal a las suscripciones — "no te pierdas la caída".

Apple Music Release

"Pre-Save Halloween Pack. NEW RELEASES."

Estética 1:1 Apple Music: featured album hero cuadrado con glyph rotando lento, lista de filas tipo "New Releases" con cover + badge (Pre-Order / Coming Soon / In Library) y botón Pre-Save. El past drop aparece con ✓ Added. Cero fricción para usuarios de iPhone — ya saben el patrón.

iOS
B&G
PROS
Patrón mental ya internalizado. El "Pre-Save" tiene altísimo CTR — pedirle al usuario un commit antes de la caída. Encaja perfecto con notificaciones FCM.
CONS
Menos sensación de "edición limitada" — los discos no se agotan. Tendría que reforzarse con "limited frames" o "tier".
Súper segura para iOS. El Pre-Save es un mecanismo de retención brutal: una vez que el user lo activa, lo notificas el día del drop y volvió a abrir la app.

Streetwear Lookbook

"10.31 — EDITION 003 / FW26. NEW RELEASE."

Estética Supreme / A24 / Off-White: la fecha es el héroe visual en Bebas Neue gigante, serial number como autenticidad ("EDITION 003 / FW26"), marquee de "NEW RELEASE · LIMITED EDITION" arriba. Cada drop tiene un color accent distinto (orange / rose / emerald). El archive abajo muestra "SOLD OUT" como estatus de coleccionismo.

iOS
B&G
PROS
Súper on-brand para Pixora. Escalable a cualquier evento (solo cambia color accent + fecha). Bebas Neue gigante = anclaje visual brutal. El "SOLD OUT" en archive crea FOMO real.
CONS
Requiere visuales fuertes — un crop mal hecho rompe la estética. Bebas Neue puede sentirse "fashion" para users casuales.
La más "Pixora" de las cinco. Esta sí podría ser la identidad de la sección por defecto — cool, premium, no necesita justificar nada con copy.

Gallery Mint

"247 / 500 minted. Edition 128 owned."

Estética OpenSea / Magic Eden / Foundation: stats arriba (X / Y minted con tick animado + tier badge LEGENDARY / RARE), frame del wallpaper con scanline, "Mint Now" / "Reserve" como CTA. Wallet chip muestra cuántos posee el usuario; "MY COLLECTION" abajo con número de edición serial. Speak directo al collector mindset.

iOS
B&G
PROS
Scarcity built-in. Edition number = trofeo único (#128 / 500). Habla a la generación crypto / collector. El "MY COLLECTION" empuja a re-engage.
CONS
Asociación crypto puede espantar al usuario casual. La palabra "Mint" puede confundir. Requiere traducir GEMS = créditos Pixora.
Genial para Pixora porque YA tenemos créditos (diamantes) — el "MINT · 80 GEMS" embona con el sistema existente sin meter crypto real. Cool sin el riesgo regulatorio.

Vogue Runway

"OCT 31 · MX CITY · by Pixora. Reserve Front Row."

Estética Vogue Runway / fashion week invitation: masthead "PIXORA RUNWAY", título serif italic gigantesco (DM Serif Display) sobre crop del wallpaper, "Runway Show 003" deslizándose a la izquierda, season tag FW26, ciudad + designer credit ("by Pixora") y "Reserve Front Row" CTA. Past Collections con look de archivo editorial.

iOS
B&G
PROS
VERY premium / aspirational. El designer credit "by Pixora" eleva la marca. DM Serif Display + italic = elegancia sin caer en cosmic. "Reserve Front Row" tiene un copy cool y único.
CONS
Aesthetic nicho — fashion-savvy users lo aman, casuales pueden no entenderlo. Menos "drop urgency" que SNKRS.
Para Pixora premium / iPhone audience — el que paga gusta lo aspirational. Encaja perfecto con B&G theme. El más diferenciador si Pixora quiere posicionarse como "luxury wallpapers".
